# COBOL Student Account Test Plan

This test plan captures the current behavior of the COBOL student account
application. It is intended for business-stakeholder review and as a baseline
for unit and integration tests during the Node.js modernization.

**Execution notes**

- Each test that starts a new application run begins with an in-memory balance
  of `1000.00`.
- `Actual Result` and `Status` are intentionally left for the test executor to
  complete. `TBD` means the test has not yet been executed.
- Amounts use two decimal places unless the scenario specifically tests input
  handling.
- The displayed balance is zero-padded to the COBOL field width, for example
  `001000.00`.
